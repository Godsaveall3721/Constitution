## 对象分层

为了让项目原子化，建议先统一成这些基础对象：

- `member`：公民、议员、候选人
- `seat`：席位
- `body`：共和国议会、大区议会、省议会、广域市议会、公社委员会等合议体
- `office`：总统、总理、议长、主席等单一职务
- `procedure`：选举、任命、解散、公民复决、弹劾、违宪审查、解释、条款暂停
- `document`：法案、命令、决议、修正案、条约
- `registry`：对象总线、链表、注册表
- `rule`：选举规则、表决门槛、任期、改选规则

## 建议实现顺序

1. `types`、`result`、`macros`、`registry`
2. `member`、`seat`、`body`、`office`
3. `procedure`、`document`、`election`
4. `referendum`、`impeachment`、`law`、`court`
5. `cpp` 包装层
6. `asm` 特殊实现

## 结论

README.md 是宪法原文和总说明。

`docs/constitution-model.md` 负责把原文拆成对象、机关、程序、文书和规则。

这样以后你新增内容时，就能先判断：

- 这是“机关”还是“程序”
- 这是“文书”还是“规则”
- 这是该进 C 层，还是 C++ 层，还是两边都要有
