## 目的

本文档不是普通的语法清单，而是一个“语法博物馆”。

你想收集的不是单个零散特性，而是 C / C++ 在不同阶段、不同风格、不同抽象层里的指针、对象、内存、回调与多态。

所以这里的组织方式应该是：

- 先分“展区”
- 再分“展厅”
- 最后分“展品”

这样才能把你想要的“博物馆感”保留下来。

## 博物馆总览

### 一层：C 基础展区

这一层展示 C 最原始、最直接的用法。

重点不是“好看”，而是“能把对象钉住”。

展品包括：

- 指针
- 指针数组
- 二级指针
- 结构体指针
- 函数指针
- 宏
- `malloc` / `free`
- 链表
- 回调
- 手写状态机

这一层最像你原先的“C with class”写法。

### 二层：C 组织展区

这一层展示 C 如何从“能用”变成“能组织”。

展品包括：

- `struct` 作为对象容器
- `typedef` 作为别名系统
- `enum` 作为状态与类型
- `union` 作为共享内存表达
- `const` / `volatile` / `restrict`
- 多级指针管理对象关系
- 以函数指针表模拟方法表
- 以宏模拟构造器和派生关系

这一层对应“结构化的 C”。

### 三层：C 接口展区

这一层展示 C 如何把多个模块接起来。

展品包括：

- 头文件拆分
- 模块边界
- `extern`
- 句柄式对象
- 全局注册表
- 单例式控制点
- 中断式分发
- 对象总线

这一层很适合你的 `registry`、`body`、`procedure`、`document` 这类模块。

### 四层：C++ 基础展区

这一层展示 C++ 的基本对象能力。

展品包括：

- `class`
- 成员函数
- 构造函数
- 析构函数
- 成员指针
- 对象指针
- 引用
- `new` / `delete`
- 访问控制

这里也要单独收藏 C++ 的空值写法：

- `nullptr`
- `NULL`
- 早期空指针写法

这一层不是为了替换 C，而是为了给同一套宪法对象再开一套表达方式。

### 五层：C++ 对象展区

这一层展示 C++ 如何把对象关系说清楚。

展品包括：

- 继承
- 虚函数
- 重写
- 抽象类
- 接口风格基类
- 多态调用
- 智能指针
- `std::string`
- `std::vector`

这一层适合承载“共和国议会”“大区议会”“省议会”“广域市议会”“公社委员会”这些同类对象。

### 六层：C++ 现代展区

这一层展示现代 C++ 的资源管理与表达能力。

展品包括：

- `unique_ptr`
- `shared_ptr`
- `weak_ptr`
- RAII
- 移动语义
- 完美转发
- 模板
- `constexpr`
- `enum class`
- `std::optional`

这一层也可以继续收纳“空对象表达”与“资源归属表达”，让它和 `nullptr`、`new` / `delete` 连成一条线。

这一层适合做更干净的封装，不适合把整个项目都拖成纯 C++。

## 指针博物馆

你特别强调“每个阶段都有不同的指针”，这一点应该单独列出来。

### 第一馆：原始指针馆

展品包括：

- 普通指针
- 空指针
- 野指针
- 悬空指针
- 结构体指针
- 函数指针

这一馆还要收藏 C 的空值表达：

- `NULL`
- `0` 形式的空指针习惯写法

作用是展示最底层的对象抓取方式。

### 第二馆：多级指针馆

展品包括：

- 二级指针
- 指针数组
- 数组指针
- 指向函数指针的指针
- 指向结构体指针的指针

作用是展示对象组织、对象转交和对象迭代。

### 第三馆：成员指针馆

展品包括：

- C++ 成员变量指针
- C++ 成员函数指针
- 绑定到对象后的调用方式

作用是展示类内部结构和对象外部调用之间的关系。

### 第四馆：所有权指针馆

展品包括：

- `unique_ptr`
- `shared_ptr`
- `weak_ptr`
- 裸指针与所有权分离

这一馆还要把 C 的动态内存配套收藏进去：

- `malloc`
- `calloc`
- `realloc`
- `free`

其中：

- `malloc` / `calloc` / `realloc` 负责申请和调整原始内存
- `free` 负责释放原始内存
- `new` 负责申请并构造对象
- `delete` 负责析构并释放对象

作用是展示资源谁拥有、谁借用、谁观察。

### 第五馆：接口与桥接指针馆

展品包括：

- `void *`
- `self` 指针
- 回调上下文指针
- 中断分发指针
- 句柄到对象的映射指针

作用是展示 C 与 C++ 的交界面。

## 语言层面的分配原则

### C 负责的重点

C 层优先展示：

- 原始指针
- 多级指针
- 函数指针
- 宏
- 结构体组织
- 链表 / 注册表
- 动态内存
- 状态机
- `malloc`
- `calloc`
- `realloc`
- `free`
- `NULL`

### C++ 负责的重点

C++ 层优先展示：

- `class`
- 继承
- 虚函数
- 构造 / 析构
- 成员指针
- 智能指针
- RAII
- 模板
- `new`
- `delete`
- `nullptr`

### 两边都要出现的重点

以下内容不是只属于某一边，而是两边都要有对应表达：

- 指针
- 对象关系
- 资源管理
- 回调
- 状态转换
- 机关层建模
- 空值表达

## 展陈原则

这个项目里的“博物馆”不能只是罗列语法名词，而要体现阶段感。

也就是说：

- 同一个“指针”，在 C 里和在 C++ 里不是同一个展品
- 同一个“对象”，在 C 里和在 C++ 里也不是同一个展示方式
- 同一个“机关”，可以先用 C 方式表达，再用 C++ 方式重新表达

这样才符合你想收集的深度。

## 与实现的关系

建议按下面方式安排：

1. 先把 C 的原始指针馆和结构体馆搭起来
2. 再把函数指针、链表、注册表、动态内存补齐
3. 再把 C++ 的类、继承、虚函数、构造 / 析构补上
4. 最后再放现代 C++ 和少量 ASM 展品

这样整个项目就会像一个“不断扩建的语法博物馆”。
