# config 目录说明

这个目录用于录入《欧罗巴共和国宪法》所需的基础数据。

## 当前已启用

- `regions.csv`：行政区、人口、隶属关系
- `people.csv`：人名、职务、年龄、所属行政区

## 格式

### `regions.csv`

```text
name,kind,label,seat_name,population,parent
```

- `name`：行政区名称
- `kind`：行政区种类，例如 `共和国`、`大区`、`省`、`广域市`、`省区`、`公社`
- `label`：行政属性标记，例如 `首都`、`首府`、`中心城市`、`省会`、`副省会`；若无标记可填 `-`
- `seat_name`：政府驻地名称，只写驻地名，不加 `公社` 后缀；例如 `维也纳首都`、`巴黎首府`、`斯德哥尔摩中心城市`
- `population`：人口
- `parent`：上级行政区，`-` 表示无上级

### 层级建议

- 一级：`共和国`
- 二级：`大区`
- 三级：`省`、`广域市`
- 四级：`省区`、`公社`

这份配置已经把大区下面的二级、三级、四级行政区一并展开，并用 `label` 字段标出首都、首府、省会、中心城市、副省会；`seat_name` 负责记录对应的政府驻地名称，便于后续录入人名、议员、区长、区议会、委员会等对象。

### `people.csv`

```text
name,role,age,constituency
```

- `name`：人名
- `role`：职务或身份
- `age`：年龄
- `constituency`：所属行政区

## 说明

- 人名可以虚构
- 行政区人口以共和国总人口为基准
- 目前程序会从 `../config` 读取这些文件
