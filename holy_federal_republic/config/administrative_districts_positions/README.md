# 行政区划与职位

- `nation.csv`：联邦总统、联邦理事会职务、国会议员、联邦行政部长、驻外大使及联邦最高法院大法官。
- `nation/member_states.csv`：加盟州行政首长及按议题出席联邦理事会的州级主管部长；加盟州是本配置的最小单位，不展开州内层级。

CSV 表头为 `# name,kind,appointing_body,selection_method,term_years,basis_unit`。任期按年记录，`0.0833333333333333` 年表示一个月；`-` 表示宪法未规定。联邦总统任期为四年、可连任一届；联邦理事会执行主席由州行政首长轮值、每次一个月。

联邦国会任期为四年。总统任命行政部长和驻外大使须经国会同意及联邦理事会核准；理事会收到同意文书十五日内未提出异议视为核准。联邦最高法院法官的产生方式和任期未规定。宪法另提及联邦宪法法院，但未规定其组织或成员，且与司法权归联邦最高法院的条文关系未厘清，故不推定法官职位。
