# 议会层级配置

议会目录按国家行政层级递进：国家议会及其参议院、众议院见 `nation.csv`；`nation/region.csv` 列出大区议会；每个大区 CSV 列出该区的省议会与广域市议会；省和广域市各自的 CSV 列出其辖下公社委员会。

省区（Arrondissement of Depaertments）是辅助行政区划，不设议会。省辖公社从省区树中递归汇总到对应省议会之下；广域市辖公社列在所属广域市议会之下。`parent` 标识上一级议会，稳定 ID 由对应行政单位 ID 加议会类型后缀构成；如行政单位 ID 重复，则增加大区限定前缀。

CSV 表头为 `# name,kind,label,seat_name,population,parent`；人口和席位名称沿用对应行政单位配置中的值（缺省席位以 `-` 表示）。这里先配置议会实体与层级，选区映射另行配置。
