# 行政区划与委员会职位

本目录只配置项目 README.md 地方制度部分明文规定的行政职位和委员会职务，不登记具体在任人员。

- `nation.csv`：共和国总统、总理及政府阁员、国家议会两院职位、参议员和最高法院/宪法法院职位。
- `nation/region.csv`：大区区长、大区议会主席及大区委员会委员职位。
- `nation/region/<大区 ID>.csv`：该大区所属省和广域市的职位。
- `nation/region/<大区 ID>/<省或广域市 ID>.csv`：省区副省长职位，以及所属公社委员会委员和公社市长兼委员会主席职位。
- 广域市市长单独列为行政职位；其下公社职位列在广域市文件中。省区仅有副省长职位，不设委员会。

CSV 表头为 `# name,kind,appointing_body,selection_method,term_years,basis_unit`。职位括号内为稳定 ID；`basis_unit` 引用行政单位或议会/委员会 ID。相同职位类型按辖区分别配置，ID 保持唯一；行政单位 ID 重复时使用大区 ID 限定。

明确规定的任期按年记录；`-` 表示 README 未规定该职位任期，不推定委员会席位数量。公社市长与公社委员会主席是同一职位，仅记录一行。市政厅（Mairie）是行政机构而非职位，不单独列入。

国家级职位依共和国条文配置，条件职位在 `selection_method` 中注明。宪法法院法官条文同时规定十年任期及每八年改选半数，二者周期不一致，表内保留该矛盾，不作推定；条文未提供稳定名称或构成的委员会不列入。
