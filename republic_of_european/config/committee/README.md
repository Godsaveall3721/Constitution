# 委员会配置

本目录按 README.md 明确规定的地方行政层级配置委员会：大区委员会、省委员会、都会委员会和公社委员会。省区是辅助行政区划，不设委员会；省下公社由所属省委员会管理，广域市下公社由所属都会委员会管理。

- `nation/region.csv`：各大区委员会。
- `nation/region/<大区 ID>.csv`：该大区的省委员会和都会委员会。
- `nation/region/<大区 ID>/<省或广域市 ID>.csv`：对应行政单位下的公社委员会。
- 暂无单独的国家级委员会配置：README 未规定国家级委员会实体；宪法法院特设/常设委员会及议会一般委员会也未提供固定名称和完整实例，故不臆造配置。

CSV 表头为 `# name,kind,label,seat_name,population,parent`。名称括号内为稳定 ID；`parent` 指上一级委员会，最上级大区委员会以国家名称为父级。人口、席位沿用行政区划配置，省区不作为层级节点。
